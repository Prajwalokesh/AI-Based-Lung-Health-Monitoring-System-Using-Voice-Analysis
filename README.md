# AI-Based Lung Health Monitoring System Using Voice Analysis

## Overview

An AI-powered healthcare system that analyzes voice recordings to identify potential lung-related health conditions. The system uses audio feature extraction and a trained deep learning model to generate health predictions from voice samples.

## Features

* Voice-based health assessment
* Audio preprocessing and feature extraction
* MFCC-based voice analysis
* AI-powered health condition prediction
* User-friendly web interface
* Automated prediction results

## How It Works

```text
Voice Input
    ↓
Audio Processing
    ↓
Feature Extraction
    ↓
Deep Learning Model
    ↓
Health Prediction
```

### Voice Analysis

The system processes the user's voice recording and extracts relevant acoustic features such as **Mel-Frequency Cepstral Coefficients (MFCCs)**.

### AI Prediction

The extracted features are passed to a trained deep learning model to identify potential respiratory health conditions.

### Result

The predicted condition is returned and displayed through the application's interface.

## Technology Stack

* **Frontend:** React
* **Backend:** Python, Flask
* **Machine Learning:** TensorFlow / Keras
* **Audio Processing:** Librosa
* **Feature Extraction:** MFCC
* **Languages:** Python, JavaScript
